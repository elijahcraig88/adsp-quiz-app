# ADsP 마스터 (데이터분석 준전문가 기출문제 풀이 & 퀴즈 앱)

> **2026 ADsP 단기 합격 풀패키지**  
> 실전 기출 50문항 회차별 풀이, 문항별 상세 해설 & 오답 선지 분석, 단어/문장 퀴즈 코너(OX/초성/플래시카드/스피드), 오답노트 & 북마크, 통합 검색 사전

---

## 🚀 실행 방법 (2가지 중 편한 방법 선택)

### 방법 1. 원클릭 실행 (가장 권장)
- 폴더 내의 **`run_app.bat`** 파일을 더블 클릭합니다.
- 자동으로 브라우저가 열리며 `http://localhost:8080`으로 실행됩니다.
- 같은 Wi-Fi에 연결된 스마트폰에서도 내 PC IP:8080으로 접속하여 모바일로 문제를 풀 수 있습니다!

### 방법 2. 직접 열기
- **`index.html`** 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등 웹 브라우저에서 바로 열 수 있습니다. (별도 프로그램 설치 전혀 불필요)

## 🌟 핵심 기능 안내

### 1. 실전 기출 & 모의고사 풀이 (회차별)
- **최신 기출 완벽 수록**: 제40회(최신 기출), 제39회, 제38회, 제37회, 제36회, 제35회, 적중 모의고사 1회, 2회 등 총 400문항
- **과목별 체계**:
  - 1과목: 데이터 이해 (10문항 / 20점)
  - 2과목: 데이터분석 기획 (10문항 / 20점)
  - 3과목: 데이터 분석 (30문항 / 60점)
- **실전 시험 모드**: 90분 카운트다운 타이머, OMR 카드 실시간 마킹, 총점 60점 이상 & 과목별 40% 미만 과락 자동 판정, 최종 성적표 및 합격 축하 콘페티
- **즉시 해설 학습 모드**: 문제 풀자마자 정답 여부 확인 및 상세 해설 열람
- **과목별 집중 모드**: 1과목만, 2과목만, 3과목만 골라서 집중 풀이 가능

### 2. 문항별 초상세 해설 & 오답 선지 분석
- **정답 해설 (💡)**: 왜 이것이 정답인지 개념과 원리를 명쾌하게 해설
- **오답 선지 분석 (❌)**: 각 오답 보기가 왜 틀렸는지 1:1 반박 분석 제공
- **핵심 암기 팁 (📌)**: 시험장 직전까지 외워야 할 핵심 공식 및 요약 포인트 제공

### 3. 단어 & 문장 퀴즈 코너 (4대 모드)
1. **⭕❌ 기출 OX 퀴즈**: 실제 시험에 단골 출제되는 헷갈리는 함정 선지 참/거짓 판별 및 즉시 해설
2. **🔤 초성 빈칸 퀴즈**: 문장 속 핵심 빈칸 용어 맞추기 (초성 힌트 및 단서 힌트 제공)
3. **🃏 플래시카드 암기장**: 카드 클릭 시 3D 회전하며 정의와 팁 열람, [외웠어요 ✅] / [다시보기 🔁] 스마트 분류 저장
4. **⚡ 스피드 용어 퀴즈**: 개념 설명을 보고 4개 선택지 중 알맞은 용어 고르기

### 4. 오답노트 & 북마크 보관함
- 모의고사 풀이 중 틀린 문제는 **오답노트에 자동 등록**
- 중요 문제는 별표(⭐) 클릭으로 **북마크**
- 완벽히 이해한 문제는 **[✓ 이제 알아요!]** 버튼으로 오답노트에서 제외 가능
- 모든 데이터는 브라우저 LocalStorage에 안전하게 자동 저장

### 5. 통합 검색 & 용어 사전
- "ROC", "정상성", "CRISP-DM", "다중공선성", "이상치" 등 키워드 입력 시 전체 기출문제와 용어 사전에서 즉시 검색 및 해설 열람
